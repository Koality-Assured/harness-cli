# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.3.1] - 2026-09-22
### Added
- Host-agnostic watcher daemon
- Silent token rotation
- Worktree auto-clean

### Fixed
- Skip cross-repo tap upload when tokens are absent

## [0.3.0] - 2026-09-22
### Added
- Proactive claim watch daemon, lease ttl tracking, and scheduled task automation

## [0.2.0] - 2026-09-21
### Added
- Spoke sync, claim inspect, and secret injection
- Brews and scoops publishers and manifests

## [0.1.0] - 2026-09-18
### Added
- Standalone compiled harness binary in Go with multi-platform pipeline
